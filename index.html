Security & Server-Side API Architecture

            
Secret API keys live strictly on the backend server in environment variables (.env), never exposed in frontend code.

          

          

            
    
              
  • Environment Secrets: Stored in .env on the backend server (JWT_SECRET, AI_API_KEY, SEARCH_API_KEY, PAYMENT_SECRET_KEY).
    • 
              
  • Security Middleware: Helmet HTTP headers, CORS restriction, rate limiting, and input validation enabled in Express.
    • 
              
  • Authentication: Password hashing with bcryptjs and stateless JWT bearer tokens.
